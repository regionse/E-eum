# 잇다 — 점검 스크립트 (2026-08-06 신설)

`golden_check.py`(회귀)와 **역할이 다르다.** 여기 있는 것은 **검증**이다.

```
골든셋(golden_check)   회귀. «이미 고친 게 안 깨졌나». 계속 커지기만 한다.
홀드아웃(holdout*)      검증. «아직 모르는 게 있나». 매번 새로 만든다.
```

**골든셋 34/34 통과는 「좋다」가 아니라 「퇴행이 없다」는 뜻이다.**
실제로 골든셋에 있는 「알아들었어?」 케이스가 통과하는 동안, 화면에는
`제약 ['학력부담', '시간부족']` 이 그대로 나가고 있었다(채점기가 형태만 봤다).

## 새 홀드아웃을 만들 때의 규율

1. **버그에서 뽑지 마라.** 그러면 그건 회귀 테스트지 검증이 아니다.
   사용자 현실(실태조사·심층면접·실제 상담 상황)에서 뽑아라.
2. **이전 세트와 각도가 겹치지 않게 하라.**
   1차: 돌봄현실·정보부족·몸건강·지침짜증·경제·진입점·혼재
   2차: 오타구어체·긴발화·부정형·다중요구·질문폭탄·종료·극단짧음·메타불신
3. **정답을 미리 적지 마라.** 적으면 그것도 과적합이다.
   대신 «어겨서는 안 되는 원칙»만 자동 검사하고 나머지는 눈으로 본다.
4. **한 번 쓰고 나면 골든셋으로 승격시켜라.** 그다음엔 새로 만든다.

## holdout2 가 찾았는데 **아직 안 고친 것** (2026-08-06 기준)

```
🔴 claims_credential 오탐
   「…자격증 하나라도 따두면 좋을까요」 → 「말씀하신 자격은 확인 못 해드려요」
🔴 「응」「네」「그래서요」「나중에 다시 올게요」「너 그거 진짜야?」 → 전부 이탈
🔴 가족돌봄청년에게 «결혼 중개»를 묻는다 (태그 「돕기·돌봄+사람」에 결혼상담이 섞임)
🟡 「빨리 되는 걸로 알려주세요」가 착지 요청으로 안 잡힘
🟢 내부 어휘 노출 — 「지금까지 «식품가공» 쪽을」 (사용자는 「제빵」이라 했다)
```

이 다섯의 **원인은 하나**다 — 낱말표가 의도를 못 읽는다.
근본 해법은 `ITDA_UTT_KIND` (발화유형 판별기)이고, 코드는 들어와 있으나
**검증 전이라 꺼져 있다.** 발표준비 문서 6-4절 참고.
