# 1. 사용자(정준)와 일하는 방식 — **먼저 읽을 것**

## 1-1. 작업 절차 — 본인이 명시한 것

```
1  사고 및 판단 → 의견을 낸다
2  웹검색으로 근거를 찾는다 (최소 5개 · 신뢰성 있는 것)
3  다시 사고 및 판단
4  판정:  OK  → 그대로 수정한다
        NO  → 재조사
        edit → 사람의 도움이 필요하거나 애매함 → 물어본다
5  결과값을 낸다
6  그 결과가 «다른 코드에» 영향을 주는지 확인한다
7  끝나면 다음 케이스로
8  2번째 케이스를 건드렸으면 «1번 케이스가 안 깨졌는지» 확인.
   3번째면 1·2번을 다 확인. — 누적 회귀 확인이 필수다
```

## 1-2. 지켜야 하는 제약 — **어기면 신뢰를 잃는다**

| | |
|---|---|
💰 | **LLM 을 쓰는 검사는 «돌리기 전에» 호출 수와 비용을 보고할 것.** 제미나이 크레딧이 빠듯하다(2026-08-06 기준 1,000원 시작 → 오늘 약 200원 씀). 골든셋 1회 = LLM 42회 ≈ 30원 |
📄 | **논문은 요약을 믿지 말고 «원문»을 직접 확인할 것.** 요약 도구가 없는 수치를 지어낸 사례가 실제로 있었다(CapBencher 초록 날조). 확인 못 한 건 「미확인」이라고 적고 **발표 인용 금지** 표시를 남긴다 |
🚫 | **하위 에이전트를 중첩해서 부르지 말 것.** 예전에 토큰 2M 을 날렸다 |
⚠ | **코드 주석을 크게 믿지 말 것.** 폐기된 전제가 섞여 있다. 단서로만 쓰고 «실측»으로 확인한다. (실제로 「기본 꺼짐」이라 적힌 플래그가 `.env` 에서 켜져 있다) |
🔒 | 계정 생성·비밀번호 입력은 하지 않는다 |

## 1-3. 소통 방식

- 설명이 어려우면 **코드 말고 «그림·비유»로.** 「초등학생도 이해할 만큼」을 요구한 적 있다.
- 추측을 사실처럼 말하면 바로 지적당한다. **「안 재봤습니다」를 말하는 게 낫다.**
- 「이거 훈련생급이야? 냉정하게」 같은 질문이 온다. **아부하지 말 것.** 근거로 답한다.
- 스스로 만든 회귀를 숨기지 말 것. 오늘도 여러 건 있었고 전부 먼저 보고했다.

# 6. 🔴 밟으면 안 되는 함정

```
①  .env 에 줄 «끝» 주석을 달지 마라
      KEY=1  # 설명   →  값이 '1  # 설명' 이 되어 «조용히» 꺼진다
      설명은 줄 «위»에 쓴다.  (실제로 밟아서 플래그 5개가 꺼져 있었다)

②  _step() 의 «분기 순서»를 바꾸지 마라
      조기 return 이 20곳 넘고, 순서가 곧 사양이다
      예: 자해가 욕설보다 «위»에 있어야 「죽고 싶어요 씨발」이 자해로 간다
      옮겨야 하면 골든셋 + 다중턴을 «먼저» 돌려 기준선을 잡아라

      JOB_MIN_SCORE · SPREAD_H · CTOP_H · RR_LOW_CONF · FLAT_SPREAD
      n=52 실측으로 잡은 값이다
```

## 관통하는 프레이밍

> **재료는 흔합니다. 쓰는 법을 정한 근거가 다릅니다.**

기술 목록(하이브리드·RRF·임베딩)은 덜다도 쓴다. **약한 자리다.**
강한 자리는 **「왜 그렇게 정했나」**와 **「재보고 껐다」**.

## 🔴 발표에서 «하면 안 되는» 말

```
✗ 「LLM 을 안 믿는 구조로 짰습니다」      →  낱말 970개 있다. 첫 질문에 무너진다
✗ 「인젝션을 막습니다」                   →  슬롯 경유 · 데이터 경유 · 분할 조립은 못 막는다
✗ 「34/34 통과했으니 안전합니다」         →  3의 법칙상 참 실패율 8.8%까지 허용되는 진술
✗ 「다수결(self-consistency)을 씁니다」   →  꺼져 있다 (N=1)
✗ 「업계 평균보다 낫습니다」               →  우리가 검증할 수 없다
```

## ✅ 강한 자리

```
「만들고 재보고 셋을 껐습니다」   가중RRF · N=3 · 14/14 만점을 되돌림
「맞고 있는 사람을 가해자로」     21케이스 중 9건 오차단 → 2층 판정으로
「Scunthorpe problem」          1996 AOL 과 같은 버그. 교과서 해법 둘 다 적용
「22,470건을 «생성»해서 검사」   내가 문장을 고를 수 없다
「논문 16편 · 학회 14곳」        학습 요소를 못 쓰니 «값싼 대리»로 치환
「신호 정확도가 처벌 세기를 정함」 OOS 재현율 0.45~0.62 → 세션 종료를 안 붙임
```

## 예상 질문 — 전 기수 Q&A 에서 나온 «실제» 패턴

```
「A 를 쓰셨는데 B 도 있잖아요. 왜 A 예요?」   ← 가장 자주. 2번 나왔다
     우리 답: 가중RRF 재봤다 / 신호 14케이스 라벨 / p25=0.135 / 스윕
「이거 AI 가 짠 거죠?」                      ← 정직 + 「재보고 버린 건 사람」
「골든셋 34개로 뭘 알 수 있죠?」              ← 3의 법칙 · 트립와이어 · 22,470건
「어디까지 완성됐나요?」                     ← 먼저 말하기
「사용자 늘어나면요?」                       ← 🔴 답 없음. 숫자로 한계를 말할 것
「모니터링은요?」                            ← 🔴 「없습니다」
```

⚠ 꼬리질문이 **4단**까지 온다: 「어떻게 → 몇 개 → 효과 있었나 → 엣지케이스는」
